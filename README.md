# Evaluating the Effectiveness of NLP-Based Interventions on Academic Performance Using Machine Learning

## 📖 Overview

This project evaluates the effectiveness of Neuro-Linguistic Programming (NLP)-based interventions on students’ academic performance, psychological well-being, focus, and learning engagement using machine-learning and statistical analysis techniques.

The study combines psychological, behavioural, and academic attributes collected through structured pre-survey and post-survey questionnaires to analyze behavioural improvement after NLP intervention sessions.

---

# 🎯 Objectives

* Evaluate improvements in students’ psychological well-being, focus, and learning engagement.
* Analyze students’ responsiveness and adherence to the NLP-based intervention program.
* Examine the effectiveness of NLP-based interventions in enhancing academic performance.

---

# 🧠 NLP Techniques Used

The intervention sessions included:

* Emotional Regulation
* Positive Self-Talk
* Visualization
* Anchoring
* Cognitive Reframing
* Stress Management
* Goal Clarity Techniques

# 🤖 Machine Learning Models Used

* Logistic Regression
* Random Forest
* Support Vector Machine (SVM)
* K-Nearest Neighbours (KNN)
* Decision Tree
* Gradient Boosting
* Naïve Bayes

---

# 📈 Statistical Analysis

The following statistical techniques were applied:

* Independent T-Test
* One-Way ANOVA
* Pearson Correlation Analysis

---

# 🏆 Experimental Results

* Random Forest achieved the highest accuracy (~98.40%)
* NLP intervention improved:

  * Motivation
  * Emotional regulation
  * Focus
  * Self-talk quality
  * Behavioural adaptability
* Stress and negative emotional factors reduced after intervention
* Statistical analysis confirmed significant relationship between psychological factors and academic performance
